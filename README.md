# TOP Agent — демо

REMAX TOP-ийн агентын гар утасны апп-ын интерактив прототип (нэг HTML файл, `index.html`).
Доторх бүх өгөгдөл (нэр, утас, хаяг, гүйлгээ) хиймэл — бодит хүн, объекттой холбоогүй.
Эх код хаалттай repo-д хөгжүүлэгддэг; энэ repo зөвхөн үзүүлэнд зориулсан хуулбар.

## Өөрчлөлтийн түүх

### v6 — онбординг хот

Шинэ / дадлагажигч агентын 7 өдрийн чиглүүлэх хөтөлбөр тоглоом хэлбэрээр.

- **Дүр сонгох** (`#/onb/select`): 6 дүр, нэр оруулах сонголттой. Дүр зөвхөн харагдах байдал — coin, шагналд нөлөөлөхгүй.
- **Изометр «REMAX TOP хот»** (`#/onb`): 7 байршил, төгсөлтийн тайз, «Эхний 30 хоног» бүс. Алхам батлагдаж байршил шилжихэд дүр дараагийн цэг рүү алхана.
- **Байршлын даалгавар** (`#/onb/loc/1–7`, `#/onb/loc/30`): чеклист — баталгаажуулах, маягт, шалгалт, файл, гарын үсэг. Байршил өмнөхөө бүрэн батлуулсны дараа л нээгдэнэ.
- **Coin ба шагнал** (`#/onb/rewards`): coin зөвхөн ментор / админ баталсан (эсвэл автоматаар шалгасан) алхамд орно, 90 хоног хүчинтэй, мөнгө болж солигдохгүй. «Авах» → менежерийн ээлж.
- **Ментор** (`#/mentor`): өөрийн дадлагажигчдын алхмыг «Батлах» / «Буцаах» (шалтгаантай). **Удирдлага** (`#/admin`) дээр «Онбординг» хэсэг: админ батлах алхам, шагналын хүсэлт.
- Эрхийн шалгалт `api` давхаргад: дадлагажигч өөрийн алхмыг батлахгүй, ментор зөвхөн өөрийн дадлагажигчийг, ADMIN алхам ба шагнал олголтыг зөвхөн менежер.
- Шалгалтын асуулт, нууцлалын хуудасны текст placeholder (`[… — сургалт хариуцагч батлах]`) — агуулгыг оффис батална.
- Демо самбар: «Дадлагажигч (Э.Тэмүүлэн)» хэрэглэгч, «Онбординг · REMAX TOP хот (v6)» бүлэг.

```sh
NODE_PATH=$(npm root -g) node tests/run.js
```
